# BR Realty Website

Static website for BR Realty built with plain HTML, CSS, and JavaScript.

## Files
- `index.html`
- `styles.css`
- `script.js`
 ## Local preview
Just open `index.html` in your browser.

## Deploy to GitHub Pages

1. Create a new public GitHub repository, for example: `br-realty`
2. Upload these files
3. Commit and push to the `main` branch
4. In GitHub:
   - go to **Settings**
   - go to **Pages**
   - under **Source**, choose **Deploy from a branch**
   - choose **main** and `/root`
   - save

Your site will be available at:

`https://YOUR_USERNAME.github.io/br-realty/`

## Things to customize
- Replace `info@brrealty.com`
- Replace `(555) 123-4567`
- Replace images with your own branding/project photos
